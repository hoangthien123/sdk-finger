==================================================
SecuGen Unity 20 Bluetooth Low Energy DK Revisions
==================================================

SecuGen Unity 20 BLE Devices make use of the Bluetooth Generic Attribute Profile (GATT).
The earliest revision of Unity 20 BLE uses a GATT server with an internally 
generated UUID. The mass production release uf Unity 20 BLE uses a GATT
server with a UUID generated by Bluetooth SIG (bluetooth.com)

More information can be found at https://www.bluetooth.com/specifications/gatt/services/

Revision1 - DK for use with early release of Unity 20 BLE Devices.
 	Blue label on device
	Serial Numbers U31190100000030 ~ U31190100000034
	Firmware version 0.711D

Revision2 - DK for use with mass production release of Unity 20 BLE Devices.
 	Blue label on device
	Serial Numbers U31190100000035 and above
	Firmware version 0.712D and later
	GATT Server with UUID 0xFDA0 registered at bluetooth.com
