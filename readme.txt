Release Notes:
=================================================================
1. This version supports the following SecuGen devices:

   Unity 20 Bluetooth Serial Port Profile (SPP) Edition
   White label on device
   Firmware 0.709D or later

   Unity 20 Bluetooth Low Energy (BLE) Edition.
   Blue label on device
   Firmware version 0.711D or later

3. DK folder structure
        +- BLE - Unity 20 BLE DK
        +- SPP - Unity 20 SPP DK
	+- FMS Protocol Manual (SG1-1710B-004).pdf - Unity 20 Bluetooth comms protocol
	+- readme.txt - This file
        +- sdatest-0.52.exe - Windows utility for testing Unity Bluetooth
	+- sgbledev.dll - Windows library for SDATest BLE comms.
	+- UN20 Serial Fingerprint Management System Developer's Guide (SG1-1710A-003).pdf
        +- Unity 20 Bluetooth Datasheet (SG1-1021B-002).pdf - Unity 20 datasheet
	+- Unity 20 Bluetooth User Guide (SG1-0007J-006).pdf - User instructions
